值班人员原先需要一遍遍重复：在洗衣管家里点条码框、输入条码、点上传图片、找到那个条码的文件夹、全选、回车。 现在把这些动作交给程序：导入导出的清单，点一下【开始执行】，它会按流程逐个条码自动完成， 并把每一条的成功 / 失败结果整理成表格导出。

本说明讲三件事：程序如何还原《绘图1》里的流程图、怎么校准与使用、以及出问题时怎么处理。

01

概览：它做什么

程序是一个带图形界面的 Windows 小工具，与洗衣管家软件配合使用，处理整批“给条码上传衣物照片”的工作。全过程只有三步：

  • 导入清单 —— 读取从系统导出的 CSV（条码,文件位置），自动识别编码与表头，逐行检查条码、文件夹是否存在、文件夹里有几个文件；
  • 自动执行 —— 对清单中每一条，按流程图自动操作洗衣管家：输入条码 → 进入拍照页 → 上传图片 → 选好该条码文件夹内的全部照片；
  • 输出结果 —— 实时状态列表 + 运行日志，结束后自动导出 CSV / Excel 结果表和日志文件，失败条目附现场截图。

几个关键设计，是为了在你店里真实可用：

  • 不靠固定死坐标 —— 支持“窗口相对坐标”与“图像锚点”两种定位方式，窗口挪动后程序仍能找到按钮；
  • 精准模式（调试端口） —— 软件带调试端口运行时，程序直接按内部路由识别页面、写入条码、自动打开「选择图片」文件框、选中该订单全部照片后确认上传（与人工操作一致，照片多时自动分批）；并自动跳过已有照片的订单，防止重复上传；
  • 调试模式自动保障 —— 每次运行前自动检查：软件没开就自动以调试模式启动；开着但没带调试参数会询问后自动重启；都不可行时自动退回兼容模式；
  • 随时可停 —— 界面【停止】按钮之外，鼠标猛甩到屏幕左上角、或按 F12 都能紧急停下；
  • 先测一条 —— 【测试第一条】只跑第一行，确认无误后再整批执行；
  • 失败不丢数据 —— 失败条目记录原因并截图，修正后再次执行会从失败处继续，已成功的不会重跑。

03

使用四步

01

导入清单

点击【导入清单文件…】选择导出的 CSV。程序自动识别 GBK / UTF-8 编码、识别“条码 / 文件位置”两列，并逐行体检：

  • 条码为空 → 标记跳过；
  • 文件夹不存在 / 文件夹为空 → 在说明列提示（仍会尝试执行）；
  • 正常 → 显示文件数，状态“待执行”。
02

坐标校准（首次使用必做，约 1 分钟）

打开洗衣管家并摆好窗口，点【坐标校准…】，采集 4 个操作点（① 条码输入框、② 左侧导航「更多」、③ 更多页「拍照」、④「上传图片」），并建议加采 3 个「页面标志」（⑥ 首页 / ⑦ 更多页 / ⑧ 拍照页，只截锚点）——用于让程序识别当前页面、避免多余点击。 采集时鼠标移到目标上，倒计时结束自动记录（也可按 F2 立即记录）。

03

开始执行

先点【测试第一条】观察全流程是否正确；再【▶ 开始执行】处理剩余条目。运行中可【暂停 / 继续 / 停止】，急停可猛甩鼠标至屏幕左上角或按 F12。

04

查看与导出结果

执行中列表实时更新状态，日志区全程记录。结束时会自动把结果导出到 输出结果\ 文件夹（CSV + Excel + 日志），可点【导出执行结果】再次导出。

04

界面导览

主界面从上到下四个区，按顺序使用即可：① 导入清单区（选择文件与识别摘要）、 ② 识别结果 / 执行状态区（列表双击某行可直接打开该条码的文件夹）、 ③ 执行控制区（开始 / 测试 / 暂停 / 停止 / 演练模式）、 ④ 运行日志区。底部还有【坐标校准】【打开配置文件】【打开输出文件夹】【导出执行结果】。

小技巧：勾选「演练模式」后程序只移动鼠标、不真正点击输入，适合在正式运行前确认各校准点是否对准； 勾选「出错即暂停」可在某条出错时停下来人工处理，而不是继续跑后面的。

05

坐标校准要点

  • 模式选择：默认「窗口相对」——窗口平移后仍有效，建议保持；显示器缩放比例不要中途更改。
  • 窗口识别：程序会自动锁定「洗衣管家」主窗口（避开本工具与浏览器窗口）；采集时若提示“该点不在窗口范围内”，说明点偏了或窗口不对，请重新采集。
  • 页面识别：程序执行时先识别“当前在哪一页”再决定动作——在首页才点「更多」、在更多页才点「拍照」、已在拍照页直接上传，避免多余点击；可随时用【测试页面识别】验证（本机已预置首页/更多页/拍照页指纹，无需手动截取 ⑥⑦⑧）。
  • 锚点（进阶）：对每个按钮可【截取锚点】保存按钮小图；勾选“启用图像锚点”后程序优先用图像找按钮，更稳。
  • 验证：每采集一项点一次【测试走位】，鼠标会移到该点，肉眼确认对准后再保存。
06

执行结果与导出

列表中的状态分为四类：成功 / 失败 / 跳过（条码或文件夹无效）/ 进行中。 再次执行时，已成功的条目不会重复执行，失败的可修正后重跑。

08

常见问题

Q1点【开始执行】提示找不到窗口？
请先打开洗衣管家软件再执行；若窗口标题变化，可在 config.json 的 window.title_keyword 中改成标题里稳定出现的字样。
Q2点击的位置偏了 / 总点不中？
多为显示缩放或窗口被移动缩放引起。重新校准相关项目，或启用图像锚点模式；同时尽量保持显示器缩放设置不变。
Q3「上传图片」后没有出现文件对话框？
把 timing.dialog_timeout 调大（如 12），并确认④号点确实落在「上传图片」按钮上。
Q4某一条失败了怎么办？
看日志与 输出结果\出错截图\ 里的截图定位原因，处理后在界面点【开始执行】——已成功的会跳过，只重跑未完成部分。
Q5清单里“文件位置”与实际照片目录不一致？
程序严格按清单中的路径执行。请以实际照片所在的文件夹（例如 E:\收衣照片\<条码>）为准导出清单；导入时的“文件夹不存在”提示会帮你提前发现。
Q6中途想停怎么办？
点界面的【停止】；或把鼠标快速甩到屏幕左上角（FailSafe 急停）；或按 F12（需安装 keyboard 库，已预装）。停止后建议人工看一下软件当前页面，再继续。
Q7双击启动程序时黑窗口一闪、或提示“'-3' 不是内部或外部命令”？
这是早期启动脚本的编码/换行兼容问题（导致 Windows 把启动命令拆断），目前版本的 启动程序.bat 已重写修复（纯英文兼容脚本 + 依赖自检 + 崩溃弹窗）。若再遇到启动异常，请查看程序目录下自动生成的 启动错误日志.txt。
Q8点【开始执行】后全是“成功”，但洗衣管家毫无反应？
早期版本存在“窗口识别错误 / 点击落空却仍报成功”的问题。新版已修复三层：①自动避开本工具与浏览器窗口，锁定「洗衣管家」主窗口并强制切到前台，激活失败会直接报错；②「选择图片」对话框未出现或未关闭时，该条直接判定失败（不再假成功）；③演练模式结果统一带 [演练] 标记。若曾用旧版采集过校准点（坐标里可能出现负数），请重新校准一次。
Q10程序怎么保证不重复上传照片？
精准模式会在每条订单加载后检测“已有照片数量”：已有照片的订单自动跳过（结果里显示“跳过：订单已有 N 张照片”）；演练模式下会逐条预检查并显示每个订单已有多少张照片。如需强制上传，可在 config.json 中把 options.skip_if_has_photos 设为 false。
Q11如果调试端口连不上？
一般不用管：每次运行前程序会自动确保调试模式——软件没开会自动以调试模式启动；开着但没带参数会弹窗确认后自动重启（正常关闭失败时自动强制结束进程再重启，过程实时显示日志）；实在连不上时自动退回“图像锚点/坐标”模式，功能不受影响。
Q12怎么安装到电脑上 / 换电脑怎么办？
使用随附的安装包（安装包\洗衣管家上传助手_安装包_v1.1.exe）：双击安装、中文向导、无需管理员权限，装完自动创建桌面快捷方式；包内已含全部运行依赖，目标电脑无需安装 Python。
Q9怎么避免程序点来点去、做多余的操作？
在【坐标校准】里采集 ⑥⑦⑧ 三个「页面标志」（只截锚点），并勾选“启用图像锚点与页面识别”。运行时程序会先识别当前页面：在首页→点「更多」；在更多页→点「拍照」；已在拍照页→直接进入上传，不再有多余点击。可随时用【测试页面识别】按钮验证。
09

安全须知

  • 程序只模拟鼠标与键盘操作，不直接修改洗衣管家的数据；但它会真实操作软件，首次使用务必先【测试第一条】；
  • 执行期间请勿手动抢鼠标键盘，避免与程序操作“打架”；
  • 建议在业务空闲时段首次批量运行；分批小量跑顺后再全量；
  • 急停后（左上角 / F12 / 停止按钮），人工确认软件状态、必要时手动纠正后再继续。
下一步建议

1. 在用餐高峰前先跑 3～5 条试运行，观察耗时（单条约 10～20 秒，视电脑而定）；

2. 如照片目录规则变化（如“桌面”与“收衣照片”），同步调整清单导出规则；

3. 如需把流程扩到更多电脑 / 更多操作步骤，可基于现有步骤配置扩展。
