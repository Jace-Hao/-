# 洗衣管家 · 照片批量上传助手

根据操作流程图（绘图1）与导出清单格式编写的自动化小程序：**导入清单 → 自动识别 → 自动操作洗衣管家软件上传照片 → 输出执行结果**。

> 📄 想先看图文版说明：双击打开 **`程序说明.html`**（含界面截图、流程图还原与常见问题）。

> 适用场景：洗衣管家（Windows 桌面版）中，为一批条码逐个「输入条码 → 上传图片 → 选择该条码文件夹内全部照片 → 循环」的重复劳动，全部交给程序自动完成。

---

## 一、运行环境

- Windows 10 / 11
- Python 3.10+（本机已使用 `py -3` 指向的 Python 3.14 验证通过；安装 Python 时需保留 tcl/tk 组件）
- 依赖库安装（只需一次）：

```bat
py -3 -m pip install -r requirements.txt
```

本机已预装齐全，可直接运行。

## 二、启动

双击 **`启动程序.bat`**，或命令行：

```bat
py -3 main.py
```

## 三、使用步骤（四步）

### ① 导入清单

点击【导入清单文件…】，选择导出的 CSV 清单。程序会自动：

- 识别文件编码（GBK / UTF-8 均可）；
- 识别表头列（`条码`、`文件位置`，列名不一致也能按前两列解析）；
- 逐行校验：条码是否为空、文件夹是否存在、文件夹内有多少个文件。

识别结果直接展示在“识别结果 / 执行状态”列表中。

### ② 坐标校准（首次使用必做，约 1 分钟）

点击【坐标校准…】：

1. 先打开「洗衣管家」软件并调整好窗口位置（建议之后不要再移动窗口；使用“窗口相对”模式时窗口移动也不影响，但缩放不行）。程序会自动锁定「洗衣管家」主窗口（避开本工具与浏览器窗口）；若采集时提示“该点不在窗口范围内”，说明点偏了或窗口不对，请重新采集；
2. 在列表中选择项目 → 点击【采集坐标】→ **3 秒内把鼠标移到目标按钮上**（装了 keyboard 库时可直接按 **F2** 立即记录）→ 自动记录；
3. 需要采集的位置：

**操作点（点击位置）**：

| 序号 | 项目 | 对应操作 |
|------|------|----------|
| ① | 条码输入框 | 拍照页左侧「请输入衣物条码号」输入框 |
| ② | 「更多」按钮 | 左侧导航栏里的「更多」（用于自动切页，选配但建议） |
| ③ | 「拍照」按钮 | 更多功能页 →「收衣操作」区域的「拍照」 |
| ④ | 「上传图片」按钮 | 拍照页右下角的「上传图片」 |
| ⑤ | 对话框文件名框 | （可选）“选择图片”对话框底部的文件名输入框 |

**页面标志（用于“页面识别”，避免多余点击，建议采集）**：

| 序号 | 项目 | 对应操作 |
|------|------|----------|
| ⑥ | 首页标志 | 停在首页「收衣」大卡片上的一小块固定内容 |
| ⑦ | 更多功能页标志 | 停在“更多”页某个功能格子图标/文字上 |
| ⑧ | 拍照页标志 | 停在拍照页「请输入衣物条码号」输入框或「查询」按钮附近 |

> ✅ 本机已预置：根据你提供的页面参照图，程序已装好 首页 / 更多页 / 拍照页 的页面指纹（存于 `anchors` 目录），无需手动截取 ⑥⑦⑧；直接点【测试页面识别】验证即可。以后界面改版时，再用 ⑥⑦⑧ 重新截取。

4. 【测试走位】可让鼠标移动到已记录位置，肉眼确认是否对准；
5. 【截取锚点】：把鼠标放在目标按钮（或页面标志）上，截取一小块图作为“图像锚点”；页面标志**只需截锚点、不需要采集坐标**；
6. 勾选上方的【启用图像锚点与页面识别】，让锚点生效；
7. 点【测试页面识别】验证：程序应报出“当前识别为：【某某页】”——说明运行时会先识别页面、再决定是否点击（例：已在拍照页 → 直接进入上传，不多点任何按钮）；
8. 【保存并关闭】。

> 坐标模式说明：默认“窗口相对”——记录的是相对洗衣管家窗口左上角的偏移，窗口平移后仍然有效。
> 若使用“屏幕绝对”模式，请勿移动/缩放窗口。

### ③ 开始执行

- 建议先点【测试第一条】，只执行第一条记录，人工观察一遍全流程是否正确；
- 想更保险：先勾选【演练模式】跑一遍——程序只把鼠标移动到各按钮位置、不真正点击，用于确认校准点是否对准；
- 确认无误后点【▶ 开始执行】；
- 运行中可【暂停】（当前步骤完成后停住）/【继续】/【停止】；
- 急停：**鼠标猛甩到屏幕左上角**，或按 **F12**（需安装 keyboard 库）。

每条记录自动执行以下操作（即流程图还原）：

```
点击条码输入框 → 输入清单中该条码，回车
   ↓（自动识别当前页面：在首页→点“更多”，在更多页→点“拍照”；已在拍照页则跳过——不产生多余点击）
点击「上传图片」→ 弹出“选择图片”对话框
   ↓
输入该条码对应的存储位置（清单中的“文件位置”）→ 回车进入文件夹
   ↓
全选文件夹内全部文件（Ctrl+A）→ 回车确认
   ↓
下一条……直到清单结束
```

> **精准模式（调试端口，当前已启用）**：程序会自动连接洗衣管家的调试端口（桌面快捷方式已带调试参数），通过软件内部接口完成：
> 页面识别（按路由，不会认错）、输入条码、自动点击【上传图片】打开系统“选择图片”文件框并选中该订单全部照片后确认（与人工操作一致；照片较多时自动分批）；
> 并会**自动检测订单已有照片并跳过，防止重复上传**。演练模式下会逐条预检查（只读、不上传）。
> 若调试端口不可用（例如软件未经调试参数启动），程序会自动退回“图像锚点/坐标”模式。
>
> **调试模式自动保障**：每次点【开始执行 / 测试第一条】前，程序会自动检查——若洗衣管家没开，就自动以调试模式启动它；若开着但没带调试参数，会弹窗确认后自动重启（正常关闭失败时会自动强制结束进程再重启，整个过程在界面上实时显示进度，不会卡界面）；都不可行时自动退回“图像锚点/坐标”模式。

### ④ 查看 / 导出执行结果

- 执行中：列表实时显示每条状态（成功 / 失败 / 跳过）、日志区完整记录；
- 执行结束：自动导出结果到 `输出结果\` 文件夹：
  - `执行结果_时间戳.csv`（Excel 可直接打开）
  - `执行结果_时间戳.xlsx`（含汇总页）
  - `运行日志_时间戳.txt`
  - 出错的记录会额外保存现场截图到 `输出结果\出错截图\`。

## 五、修改指南（想调整时改哪里）

| 想改什么 | 改哪里 |
|----------|--------|
| 窗口标题关键字、坐标模式 | `config.json` → `window` |
| 采集/调整按钮坐标 | 软件里【坐标校准…】，或直接编辑 `config.json` → `points` |
| 各步骤等待时间（电脑慢就调大） | `config.json` → `timing`（如 `after_enter`、`dialog_timeout`） |
| 全局速度倍率 | `config.json` → `timing.speed_factor`（调大更慢更稳） |
| 对话框标题关键字 | `config.json` → `dialog.title_keywords`（默认 选择图片/打开/Open） |
| 出错后继续还是暂停 | 界面上的【出错即暂停】勾选框 |
| 坐标模式预热导航开关 | `config.json` → `options.warmup_nav` |
| 精准模式（端口/路由） | `config.json` → `cdp` |
| 已有照片时跳过上传 | `config.json` → `options.skip_if_has_photos`（默认 true） |

## 六、常见问题

1. **找不到窗口**：请先打开洗衣管家；窗口关键字可在 `config.json` 的 `window.title_keyword` 中修改。
2. **点击位置偏了**：多为屏幕缩放变化。推荐①重新校准，或②改用“图像锚点”模式；同时尽量保持显示器缩放设置不变。
3. **没有点开上传对话框**：把 `timing.dialog_timeout` 调大（如 12），或检查「上传图片」按钮坐标。
4. **路径输入后没有全选到文件**：多为目标文件夹为空；导入时程序会提前提示“文件夹内没有文件”。
5. **某条失败**：看日志与 `出错截图`，修正后点【开始执行】会**从失败处继续**（已成功的不会重跑）。
6. **清单里“文件位置”与实际不符**：程序严格按清单中的路径执行，请以实际照片所在文件夹（如 `E:\收衣照片\<条码>`）为准导出清单。
7. **双击启动程序黑窗口一闪、报“'-3' 不是内部或外部命令”之类的错误**：这是旧版启动脚本的编码问题，已修复（新版启动脚本为兼容格式 + 自动依赖自检）。若仍异常，请查看程序目录下自动生成的 `启动错误日志.txt` 与 `运行日志_启动控制台.txt`。
8. **点【开始执行】后结果全是“成功”，但洗衣管家毫无反应？** 旧版本可能出现“窗口识别错误 / 点击落空却仍报成功”。新版已修复：①启动时自动避开本工具与浏览器窗口，锁定「洗衣管家」主窗口并强制切到前台，失败会直接报错；②「选择图片」对话框未出现或未关闭时，该条判为失败（不再假成功）；③演练模式结果统一带 [演练] 标记。另外：若旧校准数据是在错误的参照窗口上采集的（通常表现为坐标含负数），请重新校准；程序在你校准时也会自动校验采集点是否落在窗口范围内。
9. **某条显示“跳过：订单已有 N 张照片”？** 这是精准模式的**防重复**逻辑：检测到该订单在软件里已有照片，就不再重复上传。如需强制上传，可在 `config.json` 中把 `options.skip_if_has_photos` 设为 `false`（不建议）。
10. **精准模式没连上怎么办？** 一般不用管：每次运行前程序会自动确保调试模式——软件没开会自动带参数启动；开着但没带参数会询问你是否自动重启（关不掉时自动强制结束再重启，过程有日志、界面不卡）；实在连不上时会自动退回图像锚点/坐标模式，功能不受影响。你也可以双击程序目录里的 `启动洗衣管家-调试模式.bat` 手动启动。

11. **v1.3 更新了什么？** 上传机制重写：现在会真实打开「选择图片」文件框并自动选中照片（与人工操作一致），修复此前“软件无反应、未真正上传”的问题；照片较多时自动分批上传；以“订单照片数增加”判定上传结果，未完成会标注“N/M 张，请人工核对”。

12. **v1.4 更新了什么？** 上传稳定性加固：文件选择改用「消息直写文件名框 + 直接点击“打开”按钮」通道（不依赖前台焦点与键盘），并增加多级重试与读回校验；修复个别情况下“对话框打开失败 / 无法选择文件”的问题。整批实测 24 单全部成功（含 13-14 张的大单自动分批）。

13. **v1.5 更新了什么？** 上传照片阶段会自动把「洗衣管家」窗口**强制置前并置于最顶层**（每单上传完成后自动还原），确保选照片弹窗始终处于可操作状态、不再受软件在后台/被遮挡影响；消息直写通道进一步加固（更快定位文件名框、失败更快切换备用方式）。

14. **v1.6 更新了什么？** 修复根因级问题：洗衣管家以“管理员权限”运行，而旧版工具是“普通权限”，Windows 会静默拦截普通程序对管理员程序的自动化操作（表现为：文件选择框弹出后填不了内容、一直停着）——现在工具会以管理员权限启动（本机 UAC 为静默模式，双击直接打开、无弹窗），两者同级后所有操作畅通。另修复“校验假成功”误报与超时中断问题。

## 七、安全与注意事项

- 程序只做“点击 + 键盘/剪贴板”模拟，不修改洗衣管家数据本身；
- 急停后建议人工确认软件当前页面状态，再继续；
- 首次使用务必先用【测试第一条】验证；
- 建议在业务空闲时段首次批量运行。
